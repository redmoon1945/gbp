Quick Tutorial

version : 2025-11-29 15:51:35

What you have to know beforehand

  • Future-focused: Graphical-budget-planner focuses on future projections only. It does NOT track/process past incomes/expenses.

  • How it works: You define income/expense items, which are automatically converted into financial events (specific amounts on specific dates). These events generate a "Cash Balance Curve"—a visual projection of your future balance.

  • Scenarios: Income/expense definitions are organized into "scenarios" (JSON files). You can have many scenario files, but only one is active at a time.

  • Analysis module: Use Tools → Analysis to view statistics, distributions, and summaries of your financial events.

Interacting with the Cash Balance Curve

  • Zoom in/out with the mouse scroll wheel (3 types available):

    • Scroll wheel alone: horizontal and vertical zoom

    • Scroll wheel + SHIFT: horizontal zoom only

    • Scroll wheel + CTRL: vertical zoom only

  • Pan in any direction: Click and drag on the chart with the left mouse button

  • Pan left/right by window: Use the "<" and ">" toolbar buttons to move one full window width

  • Reset scale: Click the "predefined scales" toolbar buttons to quickly reset to standard zoom levels




  • Click on a data point: The point highlights (green by default), and the right panel shows details including all financial events that occurred on that day. The displayed amount is the previous day's balance plus all transactions for that day.


Creating a new scenario






A) Select the “Scenario -> New...” menu

B) Choose the currency to be permanently associated to this new scenario, by selecting a country (1), then press Select button (2) . The new scenario will be created, with empty data. It becomes the “current scenario”.





C) Edit the data (1,2,3,4) related to the new scenario. When finished, press “Apply Changes” button (5).



(C-1) : Give name to the scenario (this is NOT the file name)

(C-2) : Optionally enter a descriptive text.

(C-3) : Define an annual inflation, to be optionally used later in the process of defining incomes/expenses. Leave to default if you don't want to use inflation (0 %).

(C-4) Define Income/Expense Items

Define all income/expense items needed for your scenario. There are 2 types:

Type Use When Examples
Periodic Amounts repeat at regular intervals Salary, rent, mortgage, insurance
Irregular One-time or sporadic transactions Bonus, gift, car repair, renovation

Using Tags to Organize Income/Expense Items

Tags help you organize and categorize your income and expense items. You can assign one or more tags to each item, making it easier to filter, analyze, and manage your financial data.


Creating and Managing Tags:

  • Use the "Tags" menu or dialog to create new tags for your scenario

  • Assign tags to income/expense items when creating or editing them

  • Examples: "Essential", "Discretionary", "Work", "Medical", "Housing"


Using Tags in Analysis:

The Analysis module allows you to filter and view financial events by tags, making it easy to see spending patterns for specific categories or understand the impact of tagged items on your overall budget.


Opening an existing scenario






A) Open an existing scenario file using the “Scenario->Open” or “Scenario->Open Recent”





B) Enter the total current cash asset you have as of today. The Cash Balance curve will start from this amount. This is NOT saved in the scenario file.






You will then see the calculated cash balance curve, derived from all the financial events generated.


Editing an existing scenario


A) Once a scenario is opened, select “Scenario->Edit” menu to bring the same window seen previously in the “Create Scenario” section


B) Do all the editing required. Everything can be changed, except the currency.


C) Once completed, press “Apply Changes” to update in memory the currently loaded scenario and thus see updates applied to the displayed cash balance curve. To discard all the changes made in the edit window, you have to re-open the same scenario file WITHOUT saving the changes made (there is no Undo...).



D) To save permanently the modifications made to the scenario, you have to explicitly save it using the “Scenario->Save” menu. Otherwise all changes will be lost when you exit graphical-budget-planner.


Analyzing a scenario

This module, available with the “Tools->Analysis” menu, provides a lot of statistical info about the financial events generated, including :

  • the super useful distribution of incomes/expenses by weight (which are the most significants over a certain period of time)

  • Monthly and yearly summaries, both in histogram form and exportable tabular form.

Troubleshooting

Q: How do I undo changes to my scenario?

A: There is no Undo function. If you want to discard changes, close the scenario without saving and reopen the file. Only use "Apply Changes" when you're sure about your edits.


Q: Can I change the currency of an existing scenario?

A: No, currency is set when creating a scenario and cannot be changed. Create a new scenario with the desired currency if needed.


Q: What does "End-of-Month" option do for periodic items?

A: When enabled, all financial events for that periodic item will occur on the last day of each month, regardless of the specific date you enter.


Q: Can I import irregular expense data from a file?

A: Yes, irregular items support CSV file import. Use the import button in the edit dialog to load dates and amounts from a file instead of entering them manually.


Q: What is the current cash asset field and where is it saved?

A: This field represents your total current balance as of today and is NOT saved in the scenario file. You must re-enter it each time you open a scenario. It determines the starting point of your Cash Balance Curve.
